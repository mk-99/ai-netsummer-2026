# Построение схемы сети (сетевой уровень, overlay)
Подготовь схему маршрутизации overlay для устройств, входящих в состав стенда. Помести схему в файл "topology_overlay.puml". Если такой файл уже есть, перезапиши его.

Для анализа можно использовать:
 - поля "description" в описании интерфейсов
 - IP-адреса
 - имеющиеся в каталоге workspace файлы инвентаризации, схемы физической топологии, схемы топологии underlay
 - выводы show-команд на твое усмотрение

На схеме должны быть изображены:
 - Устройства
 - Соединения между ними на сетевом уровне
 - Автономные системы BGP
 - BGP peers
 
Ограничения:
 - Топологию на сетевом уровне underlay и физическую топлогию анализировать не надо, используй существующие схемы
