# Построение схемы сети (физический уровень)
Подготовь схему соединений устройств, входящих в состав стенда. Помести схему в файл "topology.puml". Если такой файл уже есть, перезапиши его.

Для анализа можно использовать:
 - поля "description" в описании интерфейсов
 - IP-адреса
 - результаты вывода команд "show cdp neighbors", "show lldp neighbors"

На схеме должны быть изображены:
 - Устройства
 - Соединения между ними
 - Подписаны имена (hostnames)
 - Подписаны интерфейсы (сокращенно)
 
Ограничения:
 - Топологию на канальном и сетевом уровне анализировать не надо
