# Построение схемы сети (сетевой уровень, underlay)
Подготовь схему маршрутизации underlay для устройств, входящих в состав стенда. Помести схему в файл "topology_underlay.puml". Если такой файл уже есть, перезапиши его.

Для анализа можно использовать:
 - поля "description" в описании интерфейсов
 - IP-адреса
 - имеющиеся в каталоге workspace файлы инвентаризации, схемамы физической топологии
 - выводы show-команд на твое усмотрение

На схеме должны быть изображены:
 - Устройства
 - Соединения между ними на сетевом уровне (underlay)
 - Протоколы динамической маршрутизации
 
Ограничения:
 - Топологию на сетевом уровне overlay анализировать не надо
