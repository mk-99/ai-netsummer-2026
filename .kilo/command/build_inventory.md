# Построение таблицы инвентаризации
Подготовь таблицу инвентаризации устройств, входящих в состав стенда. Помести таблицу в файл "inventory.md". Если такой файл уже есть, перезапиши его.

В таблице должны быть следующие столбцы:
 - Имя устройства (соответствует конфигурации hostname)
 - Модель
 - Версия ПО
 - IP-адрес интерфейса управления (обычно этот интерфейс помещен в vrf Management или похожий)
