# Lab topology
Lab topology consists of the following devices:

- 10.31.251.70 Spine-1

Switches are virtual machines using Cisco Nexus image.

# Access to devices
Devices can be accessed by command line using SSH. SSH keys are pre-configured.
Username for ssh access should be "demo" with empty password. This account grants read-only access to network devices.
Please do not check ssh key on first login.

# Workspace
All files acquired from network devices and/or generated by models must be placed in "workspace" directory located at project root. This directory should be created if need.

# Rules for device access
