# ai-netsummer-2026 - мастер-класс для сетевых инженеров

## О данном репозитории

Это репозиторий мастер-класса "Использование ИИ-ассистента Джета (и ИИ вообще) в работе сетевого инженера". 


## Подготовка к работе

### Установка программного обеспечения

1. Установите Visual Studio Code (доступен по ссылке [Visual Studio Code](https://code.visualstudio.com/download)
2. Установите плагин Kilo Code из магазина приложений Visual Studio Code
3. Проверьте наличие ssh-клиента, проще всего это сделать, выполнив в командной строке команду `ssh --version`, должна отобразиться версия клиента.


### Настройка доступа к модели

1. Выберите слева плагин Kilo Code
2. Зайдите в настройки ("шестеренка")
3. Providers -> Add Custom Provider

| Параметр | Значение |
|---|---|
| Name | `jetgpt` |
| Display name | `jetgpt` |
| Base URL | `https://gpt-api.jet.su/api/v1` |
| API key | получить у организатора конференции |

Остальные параметры не меняйте.

4. Нажмите Submit

### Клонирование репозитория

1. Выполните `git clone` данного репозитория на свой рабочий компьютер
2. Откройте в VSCode (File -> Open Folder) каталог, в который вы клонировали данный репозиторий


### Работа с ассистентом

1. Проверьте в файле .kilo/rules/devices.md описания правил доступа к устройствам стенда

2. Убедитесь в наличии правильно настроенных ключей ssh для доступа к устройствам стенда

3. Задавайте вопросы ИИ-ассистенту в окне чата Kilo Code, пробуйте давать ему разные инструкции. Некоторые преднастроенные промпты доступны по нажатию `/`
   - `/build_inventory` — обнаруживает устройства стенда, строит таблицу инвентаризации
   - `/build_scheme` — строит схему соединений
   - `/build_underlay` — строит схему исходной сети (underlay)
   - `/build_overlay` — строит схему наложенной сети (overlay)
